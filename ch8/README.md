# ch8 — 변동성 돌파 전략 (한국투자증권 모의투자)

8장 실습 기록입니다. 책은 대신증권 크레온 플러스로 ETF 자동매매를 만들지만,
여기서는 **한국투자증권(KIS) Open API의 모의투자**로 바꿔서 진행합니다.
모의투자로 충분히 연습한 뒤 같은 코드를 실전 계좌로 전환하는 것이 목표입니다.

## 책과 다르게 한 이유

| | 책 (대신증권 크레온 플러스) | 이 실습 (한국투자증권 Open API) |
|---|---|---|
| 연결 방식 | 증권사 프로그램 + `win32com` | REST API (`requests`) |
| 파이썬 | 32비트, 관리자 권한 필요 | 지금 쓰는 64비트 `quant.venv` 그대로 |
| 연습 환경 | 실제 계좌, 실제 돈 | 모의투자 (가상 자금 1,000만 원) |
| 실전 전환 | - | `.env`의 `KIS_MODE`만 바꾸면 됨 |

## 준비 과정 (2026-11-17)

1. 한국투자 앱에서 비대면으로 계좌 개설: 계좌 종류는 "국내/해외 주식"
   (종합매매계좌). 개인연금, CMA는 이 용도에 맞지 않음
2. 한국투자증권 홈페이지 회원 가입 후 로그인
3. 모의투자 신청: "트레이딩" → "모의투자"에서 리그구분 "국내주식",
   1,000만 원, 3개월로 신청 → 모의 계좌번호 발급
4. KIS Developers 서비스 신청: 모의투자용과 실전투자용 APP KEY,
   APP SECRET을 각각 발급 (APP SECRET은 발급 직후 바로 저장)
5. `quant_실습\.env`에 저장 (`.env`는 git 추적 제외)

   ```
   KIS_MODE=mock

   # 모의투자
   KIS_APP_KEY=...
   KIS_APP_SECRET=...
   KIS_ACCOUNT_NO=12345678-01

   # 실전투자
   KIS_REAL_APP_KEY=...
   KIS_REAL_APP_SECRET=...
   KIS_REAL_ACCOUNT_NO=12345678-01
   ```

### 모의투자와 실전투자 구분

- `KIS_MODE=mock`(기본값): 모의투자 서버에 접속하고 `KIS_APP_KEY`,
  `KIS_APP_SECRET`, `KIS_ACCOUNT_NO`를 사용
- `KIS_MODE=real`: 실전 서버에 접속하고 `KIS_REAL_`로 시작하는 값만 사용
- `KIS_MODE`를 직접 `real`로 바꾸지 않는 한 실전 계좌로는 접속도 주문도
  되지 않음. 실전 키를 `.env`에 넣어 두기만 하는 것은 영향 없음

| | 모의투자 | 실전투자 |
|---|---|---|
| 접속 주소 | `https://openapivts.koreainvestment.com:29443` | `https://openapi.koreainvestment.com:9443` |
| 거래 코드(TR ID) 첫 글자 | `V` (예: `VTTC8434R`) | `T` (예: `TTTC8434R`) |
| 호출 간격 | 1초 (호출 제한이 낮음) | 0.1초 |

## 8_2.py — 변동성 돌파 전략의 매수 목표가 계산

### 변동성 돌파 전략

오늘 주가가 "오늘 시가 + 어제 변동폭 × K"를 넘어서면 상승 추세로 보고
매수하고, 장 마감 전에 전부 파는 단기 전략입니다. 책과 같은 규칙을 씁니다.

- 목표가 = 오늘 시가 + (어제 고가 - 어제 저가) × K, K = 0.5
- 매수 조건: 현재가 > 목표가, 현재가 > 5일 이동평균, 현재가 > 10일 이동평균
  (세 가지 모두 만족)
- 이동평균은 어제까지의 종가로 계산

### 대상 ETF

| 종목코드 | 이름 |
|---|---|
| 069500 | KODEX 200 |
| 102110 | TIGER 200 |
| 229200 | KODEX 코스닥150 |
| 133690 | TIGER 미국나스닥100 |
| 360750 | TIGER 미국S&P500 |

`8_2.py` 위쪽의 `SYMBOLS`에서 바꿀 수 있습니다.

### 실행 결과 (2026-11-17)

```
접속 대상 : 모의투자   (K = 0.5)
KODEX 200(069500)
   오늘 시가 78,510 + (어제 고가 83,770 - 어제 저가 79,350) × 0.5 = 목표가 80,720
   5일선 82,759, 10일선 83,494, 현재가 78,910  →  대기
TIGER 200(102110)
   오늘 시가 78,370 + (어제 고가 83,510 - 어제 저가 79,140) × 0.5 = 목표가 80,555

KODEX 코스닥150(229200)
   오늘 시가 10,655 + (어제 고가 11,660 - 어제 저가 10,785) × 0.5 = 목표가 11,092
   5일선 11,213, 10일선 11,131, 현재가 10,785  →  대기
TIGER 미국나스닥100(133690)
   오늘 시가 160,940 + (어제 고가 166,640 - 어제 저가 162,705) × 0.5 = 목표가 162,908
   5일선 165,209, 10일선 164,752, 현재가 161,755  →  대기
TIGER 미국S&P500(360750)
   오늘 시가 24,610 + (어제 고가 25,150 - 어제 저가 24,855) × 0.5 = 목표가 24,758
```

5개 종목 모두 "대기"였습니다. 오늘 시가가 어제 저가보다도 낮게 시작했고
현재가가 목표가와 이동평균 아래에 있어서, 매수 조건을 만족한 종목이
없었습니다.

## 8_3.py — 모의투자 주문 테스트

KODEX 200을 시장가로 1주 사고, 잔고에 들어온 것을 확인한 뒤 다시 팝니다.
장 운영 시간(09:00~15:30)에만 체결됩니다.

실행 결과 (2026-11-17):

```
접속 대상 : 모의투자
[주문 전] 예수금 10,000,000원, 총 평가금액 10,000,000원, 보유 종목 0개
매수 주문 : KODEX 200 1주 시장가, 주문번호 0000021120 (모의투자 매수주문이 완료 되었습니다.)
[매수 후] 예수금 10,000,000원, 총 평가금액 9,999,995원, 보유 종목 1개
   - KODEX 200(069500) 1주 (매도 가능 1주), 매입가 79,075원, 평가손익 +5원
매도 주문 : KODEX 200 1주 시장가, 주문번호 0000021129 (모의투자 매도주문이 완료 되었습니다.)
[매도 후] 예수금 10,000,000원, 총 평가금액 9,999,995원, 보유 종목 0개
주문 테스트가 끝났습니다.
```

- 매수와 매도 뒤에도 "예수금"이 10,000,000원 그대로인 것은, 주식 대금이
  이틀 뒤(D+2)에 결제되기 때문입니다. 이 값은 지금 주문에 쓸 수 있는
  돈과 다르므로, 자동매매에서 매수 금액을 정할 때는 그대로 쓰면 안 됩니다.

### 주문 안전장치

- `8_3.py`는 모의투자(`KIS_MODE=mock`)에서만 실행되고, 실전 모드면 주문
  없이 종료
- 실전 주문은 별도로 잠겨 있음: `KIS_MODE=real`이어도 `.env`에
  `KIS_REAL_ORDER=yes`가 없으면 `kis.py`의 매수·매도가 거부됨

## 8_4.py — 변동성 돌파 전략 ETF 자동매매

책의 `EtfAlgoTrader.py`에 해당합니다. 하루 동안 켜 두면 아래 순서로
동작하고 스스로 종료합니다.

| 시간 | 동작 |
|---|---|
| 09:00~09:05 | 전날 팔지 못한 대상 ETF가 있으면 전부 매도 |
| 09:05~15:15 | ETF 5개를 감시하다가 매수 조건을 만족하면 시장가 매수 |
| 15:15~15:20 | 보유한 대상 ETF를 전부 시장가 매도하고 종료 |
| 15:20 이후 | 종료 |

### 매매 기준

- 매수: 현재가 > 목표가, 현재가 > 5일 이동평균, 현재가 > 10일 이동평균을
  모두 만족할 때 (목표가 = 오늘 시가 + 어제 변동폭 × 0.5)
- 매수 규모: 최대 5종목, 종목당 시작 시점 주문 가능 금액의 19%
  (5종목 × 19% = 95%, 나머지는 가격 변동과 수수료 여유분). 종목당 하루 한 번
- 매도: 가격과 상관없이 15:15에 전부 매도. 손절 기준은 없음
- 알림: 시작, 매수, 매도, 오류, 매시 30분 잔고를 슬랙으로 전송

조건을 만족하는 종목이 없는 날은 매수도 매도도 하지 않고 끝나는 것이
정상입니다. 강하게 오르는 날에만 매수하는 전략이기 때문입니다.

### 책과 다른 점

- 주문은 시장가 (책은 최유리 FOK/IOC. 모의투자 지원 여부를 확인하지 못함)
- 목표가와 이동평균은 하루에 한 번만 계산 (모의투자 호출 제한 때문)
- 매도는 대상 ETF만 (책은 계좌의 모든 종목을 매도. 실전 계좌에 따로 보유한
  주식을 건드리지 않기 위함)
- 다시 실행해도 이미 보유한 종목은 다시 사지 않고, 주문이 실패한 종목도
  그날은 다시 시도하지 않음
- 매수 금액은 잔고의 예수금이 아니라 "주문 가능 금액"(매수가능조회)으로 계산

### 실행 결과 (2026-11-17)

```
[11/17 11:15:57] 자동매매 시작 (모의투자) : 주문 가능 금액 9,998,525원, 종목당 19% = 1,899,719원, 보유 종목 0개
```

이날은 5종목 모두 현재가가 목표가와 이동평균 아래여서 매수 조건을 만족한
종목이 없었습니다.

### 실행할 때 주의할 점

- 15:20까지 계속 돌아가므로 터미널 창을 닫지 않고, 윈도우 절전 모드를
  "안 함"으로 설정 (설정 → 시스템 → 전원 → 화면 및 절전)
- `Ctrl+C`로 중단하면 보유 종목이 자동으로 팔리지 않으므로 잔고를 직접 확인
- 명령 프롬프트 창 안을 클릭하면 출력이 멈출 수 있음 (`Enter`나 `Esc`로 해제)

### 겪은 문제: `EGW00201 초당 거래건수를 초과하였습니다`

모의투자 서버의 호출 제한이 예상(1초 간격)보다 빡빡해서 발생했습니다.
`kis.py`를 두 가지로 고쳤습니다.

- 호출 간격을 요청을 보낸 시점이 아니라 응답을 받은 시점부터 1초로 계산
- 이 오류가 나면 1.5초, 3초, 4.5초를 쉬면서 최대 3번 자동 재시도
  (서버가 요청을 처리하지 않고 돌려보낸 것이라 다시 보내도 중복되지 않음)

## 주의할 점

- `.env`의 키와 시크릿, 계좌번호는 README나 코드, 채팅에 적지 않습니다.
- 모의투자는 주문이 쉽게 체결되지만 실전은 호가와 거래량에 따라 체결이
  다를 수 있고, 매매할 때마다 수수료와 세금이 빠집니다.
- 모의투자는 신청한 기간(3개월)이 끝나면 다시 신청해야 합니다.
